# 数独：从规则到链

知枢学习系统（zhishu）生成的一套数独交互学习站。16 章按依赖顺序排，从规则与坐标一路走到 AIC；站点同时带可验证的求解器、出题器、诊断测试和练习场。

在线访问：<https://zrx-11.github.io/sudoku-zhishu/>

本地打开：双击 `index.html`。所有样式、内容与应用都内联在这一个文件里，不依赖 CDN，断网也能用。

## 这个站里有什么

- **16 章课程**：规则与坐标、数独的数学身份、候选数、唯一余数、隐性唯一、区块排除、数组、X-Wing、Swordfish / Jellyfish、唯一矩形、XY/XYZ-Wing、强链与弱链、解题流程、程序求解、程序出题、综合检验。
- **可下手的盘面**：每章的关键盘面可以直接看候选数；技巧页带逐步播放器，能回放目标技巧出现前的过程。
- **54 道自测题**：按章分布，答错时沿前置链回溯到可能的根因，并展开对应章节。
- **诊断测试**：随机抽 6 题，答错后按依赖图倒推，给出补课顺序。
- **练习场**：五档难度，自动候选、手动标记、撤销/重做、检查、提示、显示答案；进度与用时存在浏览器本地。
- **求解器实验室**：粘贴 81 字符盘面，数解（含多解检测）、求第一个解、按技巧阶梯评级、列完整步骤并逐步播放。
- **出题器**：从已分级题库做数字/几何变换即时出题，也可以现场随机挖洞生成；生成结果可直接拿去练习。
- **速查表、术语表、34 张抽认卡**：做题卡住时按顺序扫一遍；卡片用于主动回忆。
- **明暗主题、移动端抽屉、本地进度**。

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` | 单文件站点（构建产物，约 270 KB） |
| `manifest.json` | 知枢结构清单：章节、前置、测验、术语、卡片 |
| `.nojekyll` | GitHub Pages 关闭 Jekyll，保证下划线目录可托管 |
| `src/` | 源文件：引擎、样式、内容、应用与 HTML 壳 |
| `build_site.py` | 把 `src/` 组装成 `index.html` 与 `manifest.json` |
| `_work/` | 过程产物：引擎测试、样例搜索、题库生成、Playwright 验证与截图 |
| `README.md` | 本文件 |
| `交付说明.md` | 交付内容、验证结论、已知限制与维护方式 |

## 本地重建

```bash
python3 build_site.py
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

只依赖 Python 3 标准库与 Node（`manifest.json` 由 `_work/build/export_manifest.js` 导出）。直接打开 `index.html` 也可以，不需要起服务器。

## 验证

node _work/tests/test_engine.js          # 引擎与规则
node _work/tests/test_techniques.js      # 技巧检测与回放

node _work/verify/deep.js                # 答错倒推、诊断全流程、提示/撤销、播放器

验证记录与截图在 `_work/verify/`。

## 已知边界

- 技巧库覆盖 14 类技巧。少数公开专家题超出这套技巧库，求解器会明确显示“技巧库无法完全解出”，不会崩溃，也不会假装解完。
- Jellyfish 在随机搜索中没有找到真实盘面样例，第 9 章用文字、表格和 Swordfish 演示讲清结构；评级器仍然能识别它。
- 练习场里按“提示”只给当前盘面最简单的一步；如果盘面有冲突，会提示先检查或撤销。
- 进度存在当前浏览器的 localStorage（键 `zhishu-sudoku-v1`），换设备或清缓存不会同步。
